# Mijin Goo | CV

A minimal, single-page CV for Mijin Goo, published with GitHub Pages.

**Website:** <https://go0leum.github.io/>

## Updating the CV

Edit `assets/json/resume.json`. The page in `index.html` reads this file and renders the CV sections and social profiles.

Push changes to `main` or `master` to publish the site through GitHub Actions.

Project documents, related images, and the PDF CV are archived in `ex/` and are excluded from the published site.
